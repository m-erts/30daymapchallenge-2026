# #30DayMapChallenge 2026

Maps by [Marija Ercegovac](https://www.linkedin.com/in/marija-ercegovac) for the [30DayMapChallenge 2026](https://30daymapchallenge.com/2026/),
one folder per day: the map in English and Russian, the script that rebuilds it from open data, sources, licences and caveats.
Focus: Amsterdam and London, the Netherlands and Britain, Belgrade where it has its own story. Six days form a series on the
geography of food delivery in Amsterdam and London.
